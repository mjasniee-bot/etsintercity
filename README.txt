ETS Cleaning, GPC & Fumigation Portal
======================================

DEPLOY TO VERCEL
1. Extract this ZIP file.
2. Create a new GitHub repository and upload the index.html file and assets folder.
3. In Vercel, select Add New > Project and import the GitHub repository.
4. Framework Preset: Other.
5. Build Command: leave blank.
6. Output Directory: leave blank (or use ./ if prompted).
7. Click Deploy.

The five cards are already connected to the Google Forms and Looker Studio URLs supplied.
The ETS logo is stored at assets/logo-ets.png.
